# Lend a Hand
A group project for my Database Fundamentals and Mobile Computing courses to design a full stack Android app to allow users to help their fellow citizens
This repository contains the client side of the app, i.e the Android Studio project which gets compiled to the APK. The server side PHP and SQL are available [here](https://github.com/greatmjh/LendAHand-Backend).
# How it works (project brief)
This app allows users to help their fellow citizens. The app has a predefined list of resources that people might need, and connects people who have a surplus to those who have a shortage. For example, tinned fish or a R12 airtime voucher may be a resource.
# API parameters
The field which stores the hostname of the API server is located in the resource file `app/src/main/res/values/api_params.xml`.
